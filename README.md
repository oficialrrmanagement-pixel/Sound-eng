# Team Duck — Sound Engineer Management

Aplicação móvel/web de gestão de trabalho para técnicos de som.

## Incluído nesta versão
- Login seguro com Supabase Auth
- Dashboard/resumo
- Agenda de trabalhos/concertos
- Gestão de artistas
- Cachets e valores por receber
- Lista de equipa
- Interface responsiva para iPhone
- Ligação ao projeto Supabase existente

## Deploy
Projeto preparado para Vercel como site estático.
